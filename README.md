# 响钱 · 五分钟切片

《响钱》第一章怀表的可玩切片，以及一个用来判断“值不值得做成成品”的展示页。

- 展示页：https://shisonglin6.github.io/xiangqian-slice-demo/
- 直接试玩：https://shisonglin6.github.io/xiangqian-slice-demo/demo.html
- 玩法与验证点：[NOTES.md](NOTES.md)

## 文件

```
index.html      展示页（介绍、截图、三处共情点、玩法动词、制作现状）
demo.html       可玩切片（单文件，自包含，无外部依赖）
assets/         四张游戏截图 + bg.jpg 背景源图
NOTES.md        怎么玩、看哪三处、哪些还是占位
```

## 这是什么

1935 年，怀玉山。镇上的戏台正在演《清贫》。你在后台，隔着一层蓝布帘，替台上的人做响：钱、碗、雨、脚步。台上的人信了什么，你得亲手把它拆掉。

这不是成品。它是一个 5–12 分钟的垂直切片，用来验证两件事：玩家能不能共情；这套“做响”的动词有没有替剧本说话。

## 现状

已经有：完整可玩流程、单文件 HTML、合成占位音、剪影舞台底图、多处分支。

还是占位：手没有画；母亲只有一张侧影；声音是合成的，不是实录拟音；分支后果尚未真正拉开；没有存档、设置与移动端适配。

## 制作说明

背景图是独立生图工具生成的，不是代码画的：母亲侧影、蓝布帘、木桌、粗瓷碗、铜板、旧棉袜都在图里。代码负责字幕、透明热区、镜头推拉、明暗与 Web Audio 合成音；底图压缩成 JPEG 后 base64 内联，所以 `demo.html` 是单文件、无外部图片依赖。

早期确实试过用纯 CSS/SVG 画桌子、帘子、手、碗、袜子；手像四根香肠、观众像黑馒头，后改为生图。旧 CSS/SVG 仍留在文件里但已隐藏，只保留热区。

## 本地打开

直接双击 `demo.html` 即可。声音是 Web Audio 合成的，戴耳机更清楚；点“点击开场”开始。
